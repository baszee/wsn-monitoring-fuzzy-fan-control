Tentang

Satu sistem, dari sensor sampai kipas.

WSNova adalah prototipe jaringan sensor nirkabel. Beberapa perangkat sensor, yang disebut node, membaca suhu, kelembapan, tekanan udara, dan debu di satu area. Hasil bacaannya dikirim lewat sinyal radio, ditampilkan di dashboard web, lalu dinilai menjadi tiga kondisi sederhana.

Dari penilaian itu, sistem menentukan perintah untuk kipas. Semua tahap dapat dilihat dan ditelusuri di dashboard.

Cara kerja

Empat tahap sederhana.

Dari bacaan sensor sampai perintah untuk kipas.

1

Ukur

Node membaca suhu, kelembapan, tekanan udara, dan debu di tempatnya berada.

2

Kirim dan terima

Data dikirim lewat sinyal radio LoRa ke perangkat penerima, yang memeriksa dan menyimpannya.

3

Pantau dan nilai

Dashboard menampilkan data tiap node, lalu menilai kondisinya: Baik, Perlu Perhatian, atau Buruk.

4

Beri perintah

Node yang paling perlu ditangani menentukan seberapa kuat perintah untuk kipas.

Data menjadi keputusan

Bagaimana sistem mengambil keputusan.

Setiap node dinilai sendiri. Hasilnya digabung menjadi satu perintah untuk kipas.

  1. Bacaan masukSuhu, kelembapan, dan debu dari tiap node.
  2. Dinilai per nodeSetiap node mendapat skor, satu dari tiga kondisi, dan tingkat kendali.
  3. Yang tertinggi menentukanTingkat kendali tertinggi menjadi kendali untuk satu zona.
  4. Menjadi perintah kipasKendali zona diubah menjadi daya kipas (PWM).
  • BaikPembacaan tidak memerlukan perhatian khusus menurut penilaian sistem.
  • Perlu PerhatianAda pembacaan yang mulai perlu diperhatikan.
  • BurukPembacaan paling perlu ditangani menurut penilaian sistem.

Klasifikasi merupakan hasil pengolahan internal prototipe dan bukan penilaian baku kualitas udara. Sistem memberi perintah kepada kipas, tetapi tidak menjanjikan perubahan pada suhu atau debu.

Dashboard

Apa yang bisa dilihat dan dilakukan.

Monitoring beberapa node

Nilai terbaru tiap node dan perbandingannya tampil dalam satu halaman.

Klasifikasi kondisi

Setiap node dinilai Baik, Perlu Perhatian, atau Buruk.

Riwayat data dan keputusan

Telusuri bacaan sensor dan keputusan kendali dari waktu ke waktu.

Kendali Otomatis dan Manual

Mode Otomatis mengikuti penilaian sistem. Mode Manual hanya tersedia bagi pengguna berwenang, dan penilaian tetap dihitung.

Analisis fuzzy

Lihat bagaimana sebuah bacaan diubah menjadi kondisi dan tingkat kendali.

Simulasi

Coba nilai bayangan untuk melihat hasil penilaian. Simulasi tidak menjalankan kipas.
