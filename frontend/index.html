Prototipe penelitian Teknik Komputer

Pantau kondisi lingkungan, lihat alasan perintah fan.

Sistem ini membaca suhu, kelembapan, dan debu dari beberapa node, menilai kondisinya dengan logika fuzzy, lalu menentukan PWM fan. Setiap keputusan dapat ditelusuri di dashboard.

Tentang sistem

Dari data sensor ke keputusan fan.

Dashboard menampilkan kondisi tiap node, node mana yang menentukan perintah fan, dan berapa PWM yang dikirim. Rincian perhitungan ada di halaman Analisis Fuzzy.

Cara kerja

Alur dari sensor ke fan

Setiap tahap dapat dilihat di dashboard.

1

Sensor membaca

Suhu, kelembapan, dan debu dibaca pada setiap node.

2

Data dikirim

Data valid diteruskan melalui jaringan LoRa ke gateway.

3

Kondisi dinilai

Sistem mengubah data menjadi kondisi dan kebutuhan kendali.

4

Fan diperintah

Node dengan kebutuhan tertinggi menentukan perintah fan zona.
